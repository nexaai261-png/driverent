Tentang sistem

Data pesanan dan mobil disimpan di database Supabase, sehingga website pelanggan dan admin membaca data yang sama dari perangkat mana pun.

Login admin memakai Supabase Auth. Akun admin dibuat dan dikelola di dashboard Supabase (Authentication > Users).
